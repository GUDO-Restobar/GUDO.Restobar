## Package mapping

| Folder | Package |
|---|---|
| `src/data/` | `data` |
| `src/data/java/` | `data.java` |
| `src/data/sql/` | not compiled - SQL scripts |
| `src/pages/kiosk/` | `pages.kiosk` |
| `src/pages/manager/` | `pages.manager` |
| `src/util/feat/` | `util.feat` |
| `src/util/ui/` | `util.ui` |

## Notes

- `KioskMain.java` and `ManagerMain.java` are the only classes in the default package.
- `testconnection.java` stays directly under `src/data/` so it keeps `package data`.
- `bin/` is generated by `run.bat` and `run-manager.bat`.
- `lib/` is bundled with the project so no separate JavaFX install is needed.
